# NIL IS YOU expansion notes

This directory implements NIL as an expansion to ZERO IS YOU. The authoritative expansion contract is the supplied NIL IS YOU spec: true mathematical statements can become persistent owned facts; `SAME` is equality while `IS` remains a world-rule verb; old ZERO behavior and saves must remain compatible.

v5 ships the first testable kernel: exact rational fact parsing/truth checks, Fact Book persistence, save migration, truth/false feedback, family recognition, and the first five Fact Forge levels. Later theorem/proof-rail work should extend this kernel rather than bypassing it.
